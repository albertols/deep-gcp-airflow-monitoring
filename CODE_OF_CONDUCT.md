# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, welcome newcomers, and focus on what is best for the
community. Harassment of any kind is not tolerated.

To report unacceptable behaviour, contact the maintainers privately through the repository owner's
GitHub profile. Reports are handled confidentially.
